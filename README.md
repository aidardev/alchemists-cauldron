# 🧪 Alchemist's Cauldron

A puzzle browser game where you mix ingredients, match target ranges, and brew potions before time or lives run out.

## 🛠️ Tech Stack

- Vanilla **TypeScript**
- HTML / SCSS

## 🚀 Getting Started

```bash
# Clone the repository
git clone <your-repository-url>

# Navigate to project directory
cd alchemists-cauldron

# Install dependencies
npm install

# Run dev server
npm run dev
```
